# MarketSizer

A free, browser-based simulator for people planning a pop-up food stand. Enter worst / most likely / best
guesses; the app runs 10,000 scenarios and shows likely sales, profit, break-even and what matters most —
as pitch-deck-ready cards. Everything runs in your browser; nothing is sent anywhere.

- `SPEC.md` — model, inputs and outputs (source of truth)
- `CLAUDE.md` — project briefing and build plan
- `DECISIONS.md` — deviations and decisions log

## Develop

```bash
npm install
npm run dev      # local dev server
npm run check    # lint + format + typecheck + tests
npm run build
```
